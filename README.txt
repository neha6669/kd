# Gautam Jha Stock Learner Website

## Project files
- `index.html` — website content and page structure
- `style.css` — colors, layout, typography and mobile responsiveness
- `script.js` — Telegram button link setup
- `assets/profile.jpg` — supplied profile photo

## Run locally
Open `index.html` in a browser.

## Set your Telegram link
1. Open `script.js`.
2. Replace `https://t.me/YOUR_TELEGRAM_LINK` with your real Telegram invite link.
3. Save the file and reload `index.html`.

Both green Telegram buttons will then open the same Telegram destination.

## Publish
Upload the complete folder contents to a static website host. Keep the `assets` folder
in the same location as `index.html`.
